## 驗證（AI 自己做的）
- `pytest`：全部通過（LLM 用 fake、暫存 SQLite）；`ruff check .` 通過
- 外部 API 用法對照官方文件查核（AI_GUIDELINES §3.4）：seed 腳本用到的 12 個寫入 API。依查核結果修正了三處：PR 內文改用 `PATCH /pulls/{n}`、Notion 每個請求都帶 `Notion-Version`、Discord 建立討論串時明確指定 `type: 11`（否則預設是私人討論串）
- 用 headless Chrome 截圖檢查三個頁面，修正了窄螢幕時表格把整頁撐寬的問題
- 用真的 Claude CLI 跑三種問答模式的比較
- **實測時發現的重大問題**：第一次比較時全部失敗。原因是 Windows 上 `claude` 是 npm 的 `.cmd`，cmd.exe 會把中文的 `--system-prompt` 參數弄成亂碼，模型實際上沒有收到指示。改成用 `--system-prompt-file` 傳檔案、加上 `--json-schema` 強制結構化輸出之後，才重新跑比較。這個問題 fake provider 的測試抓不到，只有實際呼叫 CLI 才會發現
- **尚未驗證**：seed 腳本只用 mock 測過，還沒有寫入真的 GitHub / Notion / Discord（`start.sh` 已由組員在 Mac 上部署並測試，見 DECISIONS.md〈小組討論結果〉）
