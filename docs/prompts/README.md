# AI Interaction Log

依 [AI_GUIDELINES.md](../../AI_GUIDELINES.md) §2：凡是 AI 互動產生了程式碼、測試、文件，或重要的技術建議，而且進了 repo，都要在這裡留紀錄。

每一筆一個檔案，檔名 `YYYY-MM-DD-<主題>.md`，內容包含：
1. **Tool / Model**：工具與模型（知道的話）
2. **Prompt**：原文，或忠實的摘要
3. **回應 / 建議**：相關的 AI 回應
4. **驗證 / 修改**：組員驗證或修改了什麼
5. **結果**：Accepted / Modified / Rejected

如果 AI 的建議影響架構、資料 schema、依賴套件、資安或團隊流程，最後由人做的決定與理由也要寫進 `DECISIONS.md`。
