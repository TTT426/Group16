建立一個 Notion connection

Connection 是 Notion 讓其他程式讀取頁面的方式。它只看得到你分享給它的頁面，而且這裡只會讀取，不會修改任何東西。API token 只存在你這台電腦上。

建立 connection 需要 workspace 的擁有者（Workspace Owner）權限。如果你不是擁有者，請擁有者建立好之後，把 API token 私下傳給你，直接貼到下面第 2 步。

1. 建立 connection

開啟 Notion Developer portal ↗
  1. 先確認左側目前是你們團隊的 workspace（connection 會建立在目前的 workspace，之後不能搬移）。
  2. 在 Developer connections 分頁按 New connection。
  3. 名稱填〈你的專案名稱〉，Authentication method 選 API token，按 Create connection。

2. 複製 API token，貼到這裡

在 connection 的 Configuration 分頁找到 API token，顯示後複製。同一頁的 Capabilities 要勾選 Read content。

選擇要匯入的頁面

新的 connection 一開始看不到任何頁面。分享一個頁面時，底下的子頁面也會一起分享。選你們團隊放規格、會議紀錄、決策的頁面。

方法一：在 Developer portal 選頁面

  1. 回到 connection 的設定，打開 Content access 分頁，按 Edit access。
  2. 勾選要匯入的頁面和資料庫，儲存。

方法二：在 Notion 頁面上分享

打開頁面，按右上角的 ••• → Connections → + Add connection，搜尋你剛建立的 connection 並確認。

目前看得到的頁面

分享完回到這個分頁，會自動重新檢查。

匯入 Notion 頁面

會讀取 connection 看得到的每一個頁面：

  • 頁面標題與內容（標題、清單、待辦、程式碼、引用等）
  • 子頁面與資料庫裡的頁面（各自成為一份文件）
  • 建立者與時間

只會讀取，不會修改 Notion。匯入的是現在的內容；之後有更新，到「連接工具」按「重新匯入」即可。
