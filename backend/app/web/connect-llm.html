2. 設定

安裝並登入 Claude Code

  1. 依照 Claude Code 安裝說明 ↗ 安裝。
  2. 在終端機執行 claude，依照畫面用你的 Claude 帳號登入。
  3. 回到這裡按「重新檢查」。

Claude Code 已安裝並登入。

建立 API key，貼到這裡

  1. 開啟 Anthropic Console 的 API keys ↗，登入後按 Create Key。
  2. 名稱填〈你的專案名稱〉，建立後複製 key（以 sk-ant- 開頭，只會顯示一次）。
  3. 帳號需要先在 Billing 儲值才能使用。
已儲存 Anthropic API key（只存在這台電腦的 .env）。

建立 API key，貼到這裡

  1. 開啟 OpenAI 的 API keys ↗，按 Create new secret key。
  2. 名稱填〈你的專案名稱〉，建立後複製 key（以 sk- 開頭，只會顯示一次）。
使用 OpenAI 相容的服務（OpenRouter、LM Studio…）

填服務的 API 網址（通常以 /v1 結尾）。本機服務不需要 key 的話，key 可以留空。

安裝 Ollama 並下載一個模型

  1. 從 ollama.com ↗ 安裝並開啟 Ollama。
  2. 在終端機下載模型，例如 ollama pull qwen3:8b（約 5 GB，中文表現不錯）。電腦記憶體 16 GB 以上可以試 qwen3:14b。
  3. 回到這裡按「重新檢查」。
Ollama 不在這台電腦上？

填 Ollama 的網址，預設是 http://localhost:11434。

Ollama 已開啟，找到 個模型。
