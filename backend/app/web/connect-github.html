匯入

會讀取這個 repo 的：

  • Issues 和留言
  • Pull requests、留言和 code review 意見
  • Repo 裡的 Markdown 文件（README、docs 等，最多 200 個）

只會讀取，不會修改 repo。匯入的是現在的內容；之後有新的 issue 或 PR，到「連接工具」按「重新匯入」即可。
