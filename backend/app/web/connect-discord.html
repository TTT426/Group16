建立一個 Discord bot

Bot 是 Discord 讓其他程式讀取訊息的方式。這裡只會讀取，不會發訊息或修改任何東西；token 只存在你這台電腦上。

整個團隊只需要一個 bot。如果組員已經建立過，請他私下把 token 傳給你（不要貼在公開頻道），直接貼到下面第 4 步。

還差一步：開啟 Message Content Intent

沒有開啟時，bot 讀得到頻道，但每則訊息的內容都是空的。到 Bot 頁面打開它並按 Save Changes，再回來這裡。

開啟 Bot 設定 ↗

1. 建立 application

開啟 Discord Developer Portal ↗

按右上角的 New Application，名稱填〈你的專案名稱〉（伺服器成員會看到這個名字），勾選同意條款後按 Create。

2. 複製 bot token

左側選 Bot，按 Reset Token（確認後），再按 Copy。Token 只會顯示一次，之後忘記了再 Reset 一次即可。

3. 開啟 Message Content Intent

同一個 Bot 頁面往下，在 Privileged Gateway Intents 打開 Message Content Intent，按 Save Changes。

4. 貼上 token

把 bot 加入你們的伺服器

邀請需要伺服器的「管理伺服器」權限；沒有的話，請伺服器管理員幫忙打開下面的連結。Bot 只會要求「檢視頻道」和「讀取訊息紀錄」兩個權限。

邀請 bot 進伺服器 ↗
  1. 在 Add to server 選你們團隊的伺服器，按 Continue。
  2. 確認權限後按 Authorize。

匯入

會讀取 bot 看得到的頻道：

  • 每個討論串（含論壇貼文、已封存的討論串）各成為一份文件
  • 一般頻道的訊息，依時間分段
  • 發言者、時間和附件檔名

只會讀取，不會發訊息。Bot 看不到的頻道不會匯入。匯入的是現在的內容；之後有新訊息，到「連接工具」按「重新匯入」即可。
